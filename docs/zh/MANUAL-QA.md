# 手动 QA

维护者发布前要做的检查。你手上每个 macOS 版本都跑一遍；CI 只覆盖 macOS 15 和 macOS 26。

用你正在检查的那个组合对应的参数启动演示应用，或者在它的控制面板里设好同样的东西再按 **Open Settings**：

```
make demo
cd Examples/SidebarSettingsDemo && swift run --build-system native SidebarSettingsDemo --icons tiled --appearance dark
```

## 按 macOS 版本

| 检查项 | 26 | 15 | 14 |
| --- | --- | --- | --- |
| [ ] 侧边栏保留 Liquid Glass，纯色图标和方块图标都是 | 是 | 没有这种外观 | 没有这种外观 |
| [ ] 滚动列表时侧边栏的行在工具栏下方淡出 | 是 | 系统默认 | 系统默认 |
| [ ] 详情坐在窗口背景上，工具栏下面没有色带 | 是 | 是 | 是 |
| [ ] 工具栏下方的分隔线：页面顶部没有，滚动后就出现，换到新页面时又消失 | 完全没有 | 有 | 始终显示（[已知限制](ROADMAP.md)） |
| [ ] 紧凑 **Toolbar style**：侧边栏上方和下方的空隙一致 | 是 | 是 | 是 |
| [ ] 窗口以 715 × 600 打开且不能改变大小（默认配置） | 是 | 是 | 是 |
| [ ] 最小化和缩放按钮是置灰的，**Resizing** 设为可缩放时也一样；双击标题栏不会缩放窗口，窗口 › 进入全屏幕不可用 | 是 | 是 | 是 |
| [ ] 窗口在它上次所在的位置打开，跨多次启动也一样（AppKit 的 frame 自动保存） | 是 | 是 | 是 |

macOS 26 是最先暴露出用错 token 或多出背景的版本。用 `--icons plain` 和 `--icons tiled`，两种外观都检查。

侧边栏上下两端的空隙在 macOS 14、15 和 27 上是零：它一直顶到窗口边缘。macOS 26 把紧凑工具栏当作
`.automatic` 处理，所以上下两个空隙都是浮动侧边栏的内缩量。

## 按图标种类

### `.plain`

- [ ] 各行看起来像系统侧边栏：系统高度、系统字体、系统图标。在系统设置里改用户的侧边栏图标大小，它们
      也跟着变。
- [ ] 选中块是系统的高亮。
- [ ] 带色调的图标（演示应用里的 Appearance）显示自己的色调，在活跃窗口的选中行上随标题一起变白。
- [ ] 命令点按已经选中的行，页面仍保持选中。
- [ ] 方向键移动选中项。

### `.tiled`

- [ ] 每个图标坐在圆角方块上，符号是白色，位置和系统设置一样：方块左边缘到选中块边缘的距离，等于方块
      到标题的距离。
- [ ] 用 `-NSTableViewDefaultSizeMode 1`、`2` 和 `3` 启动演示应用时，方块分别是 16、20 和 24 pt，行的
      高度和同尺寸下 `.plain` 的一样，和系统设置跟随它自己的侧边栏图标大小设置一样。
- [ ] 方块取页面的色调；没有色调的页面（演示应用里的 General）是灰色。
- [ ] 行的文字是系统的，和 `.plain` 里一样。
- [ ] 选中块是系统的高亮，和 `.plain` 里一样。

## 键盘

- [ ] 纯色和方块两种样式下，刚打开窗口时上下方向键都能移动选中项。
- [ ] 输入页面标题的开头会选中那一行，纯色和方块都是。
- [ ] ⌘[ 后退，⌘] 前进；两个都随历史记录启用和禁用。
- [ ] 在窗口的任何位置按 ⌘F 都会聚焦搜索框。
- [ ] 在搜索框里，↓ 跳到搜到的页面，搜索挡住了当前显示的页面时打开第一个；之后 ↑ 和 ↓ 在搜到的页面间
      移动，在第一个上按 ↑ 仍留在列表里，Tab 回到搜索框且搜索内容保留。
- [ ] 输入一个搜不到东西的搜索词，再删掉一个字母，输入的内容仍留在搜索框里。
- [ ] 打开键盘导航（系统设置 › 键盘）后，Tab 也能到页面的控件，再回到搜索框。
- [ ] Esc 清空搜索框，列表重新显示所有页面。
- [ ] ⌘W 关闭窗口；⌘, 再次打开它，并且停在关闭时那一页。
- [ ] 用 ⌘W 关闭窗口后，Settings… 打开的是同一个窗口，不是第二个。
- [ ] 在控制面板里关掉 **Back and forward buttons** 后，⌘[ 和 ⌘] 什么都不做。

## VoiceOver

打开 VoiceOver（⌘F5），用 Tab 走一遍窗口：

- [ ] 每个侧边栏的行都读出标题，选中的行会说 “selected”。
- [ ] 后退和前进按钮读作 “Back” 和 “Forward”。
- [ ] 搜索框读出搜索提示文字。
- [ ] 窗口标题说出选中的页面，`title = .hidden` 时也一样。

## 中文界面

把系统语言设为简体中文（系统设置 > 通用 > 语言与地区），或者用 `--scenario 7` 跑演示应用，它的截图就是
用中文抓的：

- [ ] 搜索框的提示文字是“搜索”。
- [ ] 应用菜单里的条目是“设置…”。
- [ ] VoiceOver 和工具栏的溢出菜单读作“返回”和“前进”。
- [ ] 页面标题来自应用自己的字符串，在侧边栏里没有被截断。

## 其他语言

在参数后面加上 `-AppleLanguages "(ja)"` 跑演示应用，然后再换成 `"(de)"`：

- [ ] 搜索框提示文字，以及 `--scenario 6b` 时的 No Results，都是那种语言。

再加上 `-AppleLanguages "(ar)" -AppleTextDirection YES -NSForceRightToLeftWritingDirection YES`，
看看从右到左的窗口：

- [ ] 侧边栏和窗口按钮在右边，紧挨侧边栏的后退箭头指向右。

## 深色模式

用 `--appearance dark` 启动，纯色和方块各看一遍：

- [ ] 方块和选中块与侧边栏背景有区分。
- [ ] 行文字和次要文字保持对比度。
- [ ] 工具栏下方的分隔线显示出来时，在深色背景上看得清。
- [ ] 窗口开着时在系统设置 › 外观里切换浅色和深色，窗口跟着切换。

## CI 截图

发布前，下载每个 runner 最近一次运行的产物来看：

```
gh run download --name screenshots-macos-15 --dir shots-15
gh run download --name screenshots-macos-26 --dir shots-26
gh run download --name screenshots-xcode-27 --dir shots-27
```

矩阵是两种图标 × 两种外观 × `scripts/screenshots.sh` 里的场景，命名成
`macos-<major>-<icons>-<appearance>-scenario-<n>.png`。

每张图都要看：

- [ ] 窗口是 715 × 600，侧边栏宽 215 pt。
- [ ] 外观和文件名里的一致。
- [ ] 搜索框在列表上方，不在工具栏里。
- [ ] 页面标题在放得下时没有被裁切或截断。
- [ ] 头部在行之上；有底部时它在最下面。
- [ ] macOS 26 的侧边栏显示 Liquid Glass；macOS 15 没有。

逐个场景检查它额外带来的东西（清单也在 [DEVELOPMENT.md](DEVELOPMENT.md) 里）：

- [ ] `1`：三行，默认窗口。macOS 15 上，页面上方的工具栏是页面的颜色，无论窗口活跃与否、指针在上
      还是不在。
- [ ] `2`：一个长页面打开在末尾，滚动到工具栏之下。
- [ ] `3`：40 多行，侧边栏滚到最后一页，并且那一行是选中的。
- [ ] `4`：三个分组，用间距隔开，没有标题。
- [ ] `5`：行上方的账户头部滚走；高的底部留在最下面，不被裁掉。
- [ ] `6`：搜索只显示匹配的页面。
- [ ] 控制面板的每种工具栏样式下，后退和前进箭头下面都不显示标签。
- [ ] 关掉 **Back and forward buttons** 后，标题与页面的分组表单对齐，而不是贴着侧边栏。macOS 26 上，
      记下它在哪儿，以及它前面有没有一块空的玻璃形状。
- [ ] `6b`：搜不到任何东西时，一个小放大镜下面显示一行小的浅色 “No Results”，清空搜索后所有页面回来。
- [ ] `7`：60 个字符的标题用省略号截断，而不是把侧边栏撑宽；文字是中文。
